# 🦐 Sea Camarão - E-commerce

## 📋 Sobre o Projeto

Plataforma de e-commerce completa para venda de frutos do mar online, oferecendo uma experiência de compra intuitiva para clientes e funcionalidades robustas de gerenciamento para administradores.

## ✨ Principais Funcionalidades

### 🔐 Autenticação de Usuários
- Login e registro de clientes
- Níveis de acesso diferenciados (administrador/cliente)
- Recuperação de senha

### 📦 Produtos
- Cadastro, edição e exclusão de produtos
- Busca avançada e filtragem por categorias/preços
- Visualização detalhada com imagens em alta resolução
- Sistema de avaliações e comentários

### 🛒 Carrinho de Compras
- Adição/remoção de itens com interface amigável
- Ajuste de quantidades em tempo real
- Cálculo automático de totais
- Finalização de pedido via WhatsApp integrado

### 📋 Pedidos
- Histórico completo de pedidos para clientes
- Detalhes completos de cada transação
- Controle de status (pendente/em processamento/concluído)
- Notificações por email

### 📊 Dashboard Administrativo
- Visão geral de pedidos pendentes e vendas
- Gráficos e estatísticas de desempenho
- Acesso rápido às principais funcionalidades
- Gerenciamento de estoque

## 🛠️ Tecnologias Utilizadas

### Frontend
- React 19
- TypeScript
- Tailwind CSS
- Material UI
- React Hook Form + Zod para validação
- React Router DOM
- React Hot Toast

### Backend
[Link do Repositório Backend](https://github.com/mtrodrigo/user_client_api.git)
- Node.js
- Express
- MongoDB
- JWT para autenticação

## 🚀 Como Executar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/mtrodrigo/seacamarao.git
   cd sea-camarao
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Acesse a aplicação em `http://localhost:5173`
